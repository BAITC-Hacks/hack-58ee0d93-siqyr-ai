# Независимая synthetic проверка AI v0.2

12 вручную написанных вымышленных текстовых встреч: RU, KK, mixed. Аудио и реальные записи не использованы. `manifest.json` фиксирует SHA входов; `expected.json` хранит эталон отдельно. Проверка не добавляет эталон в prompt, few-shot, ответ модели или repair-вызов. До первого измерения набор не раскрывать агенту, который правит извлекатель.

Покрытие: самоидентификация говорящего; упоминание другого человека без привязки голоса; неразборчивое и неоднозначное имя; внешний отдел; неизвестный/перекрытый голос; две задачи с разными датами в одном сегменте; настоящий конфликт и неподтверждённый перенос срока; индексы, цитаты и причины review.

Из корня проекта:

```sh
.venv/bin/python eval/ai_quality_v2/check.py validate
.venv/bin/python eval/ai_quality_v2/check.py guard
.venv/bin/python eval/ai_quality_v2/check.py run --base-url http://127.0.0.1:11434/v1 --model '<явное имя локальной модели>' --output eval/ai_quality_v2/first_local_raw.json
.venv/bin/python eval/ai_quality_v2/check.py score --output eval/ai_quality_v2/first_local_raw.json
```

`guard` подставляет два некорректных ответа модели в продуктовый `propose()` и требует отказа с событием `error`: несуществующий индекс и цитата, отсутствующая в raw тексте. `run` вызывает продуктовый `backend.agents.runner.propose()` через существующий `backend.app.llm` с отключённым cache и допускает только явный loopback HTTP endpoint. Файл raw записывается до чтения `expected.json`; повторный запуск не перезаписывает первый результат. `score` отдельно выводит PASS/FAIL каждого случая и конкретные расхождения.

Для короткого регрессионного повтора `run` и `score` принимают `--cases <id> <id> ...`. Проверка SHA и manifest по-прежнему относится ко всему `inputs.json`; raw содержит `selected_cases`. Такой повтор не заменяет первый независимый baseline.

Для отдельно разрешённого hosted synthetic измерения нужны `--hosted --base-url https://api.openai.com/v1 --model gpt-6-luna` и `LLM_API_KEY` в окружении процесса. Скрипт допускает только эту пару URL/модель, проверяет pinned SHA входов и ограничивает запуск 24 вызовами. Ключ не записывается в результаты. Без `--hosted` внешний URL отклоняется.

Здесь проверяется извлечение из готового транскрипта. STT, качество диаризации аудио, серверный approve и экспорт не измеряются.
