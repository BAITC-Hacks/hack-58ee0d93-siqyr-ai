## Требования и критерии готовности

| Требование источника | Статус сейчас | Критерий приёмки к freeze |
|---|---|---|
| Русская речь | Draft STT проверена на двух записях | Повторяемый real-прогон и аудио-эталон спорных мест. |
| Казахская речь | Не проверена | Отдельный KK-фрагмент, ручной эталон, результат без подмены seed-текстом. |
| Смешанная речь | Не проверена | Фраза с переключением языка, извлечённые поля и ручная проверка. |
| Диаризация + привязка к человеку | Не построена | Автоматические speaker labels на ≥2 голосах, ручное подтверждение имён; unknown при неопределённости. |
| Поручения с ответственным и сроком | Только ручной разбор | Structured extraction, evidence, пропуски и конфликты помечены; внешний исполнитель и отдел допустимы. |
| Саммари | Ручной редактор есть; AI-генерация не подключена | Кратко отражает подтверждённое содержание, без фактов из эталонного DOCX. |
| PDF/DOCX | Клиентский DOCX и печать PDF есть; approval не подключён | Оба файла открываются, имеют одинаковые утверждённые поручения и корректный казахский текст. ТЗ пишет PDF/DOCX; команда выбирает оба формата. |
| Закрытый контур | Условие архитектуры | Без внешнего вызова на данных встречи, runtime offline smoke, tracing отключён. |
| Подключение Teams/Zoom/Meet, видео/live | Упомянуто во входах, не отдельный пункт обязательного минимума | Отложено ради загрузки аудио; показать как ограничение, при необходимости уточнить у организаторов. |
| Напоминания | Есть локальный список сроков; нет внешней рассылки | Только если остаётся время: локальный список due/overdue, без внешней рассылки; иначе честно roadmap. |

Командные пороги качества находятся в DATA.md. Это наши критерии приёмки, а не придуманные требования хакатона. Общие заявления «все демо-данные синтетические» запрещены, пока происхождение каждой записи не проверено.
