Корпоративные группы не назначают права автоматически до согласования маппинга с заказчиком.

- [2026-09-23] ЭЦП: NCALayer подписывает одноразовый challenge в браузере; backend выдаёт токен только после ответа внутреннего доверенного сервиса проверки CMS/сертификата/отзыва и совпадения payload. Пока сервис не указан, вход по ЭЦП закрыт. Для фронтенда потребуется клиент NCALayer (новая зависимость, если выбран npm-пакет).
- [2026-09-23] Профиль: настройки языка/темы/уведомлений и очищенный аватар хранятся отдельно от корпоративной идентичности в `user_profiles`. Pillow нужен для проверки формата, удаления метаданных и WebP 256×256. Смена локального пароля увеличивает версию токена и отзывает прежние локальные JWT; Keycloak остаётся владельцем корпоративного пароля.
