## Запросы на изменения у Meiirlan

REQUEST_CHANGE | `Segment.speaker` и причины проверки | При отсутствии локальных gated весов Community-1 или при одновременной речи нельзя честно присвоить `SPEAKER_00` | Было `{"speaker":"SPEAKER_00"}`; нужно `{"speaker":null,"review_reasons":["diarization_unavailable"]}` либо `"overlap"` | Потребители STT, pipeline, UI и agents | До миграции STT возвращает явные строки `UNKNOWN`/`OVERLAP`; это не подтверждённые голоса.

REQUEST_CHANGE | `RunInput.meeting_date` и `meeting_date_verified` | Upload без даты сегодня заполняется через `today(settings)`, поэтому относительный срок нельзя безопасно перевести в ISO | Было `meeting_date: date` без признака; нужно `meeting_date: date | None`, `meeting_date_verified: bool`; неизвестная дата → `null/false` | Потребители API, runner, export | До миграции runner оставляет относительные сроки только в `deadline_text`.

REQUEST_CHANGE | `AssignmentDraft.assignee/evidence/review_reasons` | Неизвестный или невыступавший исполнитель и конфликт срока требуют честного состояния и проверяемой цитаты | Было `assignee: str`, без evidence; нужно `assignee: str | None`, evidence с `segment_index`, `quote`, `field`, а также `review_reasons`, `review_status`, `confidence: None` | Потребители runner, API, БД, export, UI | До миграции неизвестный исполнитель временно `Не указан`; лишние поля v0.1 не сохраняются. Сервер должен проверять индексы и цитаты против raw сегментов.

REQUEST_CHANGE | `backend/app/pipeline.py:guard_llm_destination` | Сейчас проверяется лишь `api.openai.com` и клиентский `run.synthetic`; любой другой внешний LLM endpoint проходит, а реальная встреча может уйти за пределы ноутбука | Нужен явный provider/location allowlist: local profile допускает только подтверждённый localhost/Ollama; hosted dev — только trusted synthetic manifest, не флаг клиента; на local failure нет cloud fallback | Потребители API и runner | До изменения реальные аудио и транскрипты направлять только на проверенный localhost; `execute()` детерминированный и не должен требовать LLM endpoint.

REQUEST_CHANGE | `backend/app/exports.py` и `tests/` | На этом Mac mock approval падает без `PDF_FONT_PATH`, хотя Unicode TTF доступен по `/System/Library/Fonts/Supplemental/Arial Unicode.ttf`; полный pytest дополнительно не собирается из-за отсутствующего `scripts.demo_e2e` | Добавить проверенный Mac fallback/тестовый font fixture и вернуть отсутствующий script или поправить владельцем test import | Потребители demo/API tests | Мы не меняем эти области.

REQUEST_CHANGE | `backend/app/llm.py` и окружение OpenAI SDK | Проверка `OPENAI_API_KEY` успешна, но установленный OpenAI SDK 3.19.0 через httpx2 2.13.1 падает с `TypeError: process() takes no keyword arguments` при Brotli-распаковке ответа | Настроить `Accept-Encoding: identity` в клиенте либо согласовать совместимые зависимости; повторить реальный запрос через штатный `LLM.complete()` | Потребители hosted synthetic eval | Прямой синтетический запрос с `Accept-Encoding: identity` успешно вернул ответ модели `gpt-4.1-mini-2025-04-14`, 21 токен. ## Текущий статус

- STT: mixed TorchScript adapter находится в `backend/stt/`; локальный smoke на исходной записи прошёл, 14 непустых сегментов, каждый короче 18 секунд, исходные таймкоды сохранены. Веса скопированы из ADM в `models/stt/`, SHA256 в `models/stt/manifest.json`; бинарные файлы исключены из Git. По умолчанию adapter выбирает копию в checkout.
- Диаризация: HF token и gated доступ к Community-1 проверены. Веса скопированы в `models/diarization/` и исключены из Git; SHA256 и ревизия указаны в манифесте. Локальный smoke на 20 секундах исходного аудио определил 2 акустических голоса в 5 репликах. Полный прогон записи (~206 с) вместе с mixed STT прошёл: 45 сегментов, 5 акустических меток, 1 `OVERLAP`, последняя граница 205.84 с, максимальная длина сегмента 12.79 с. Текст записи никуда вовне не передавался.
- Извлечение: первый независимый замер `qwen3:4b` через локальный Ollama с JSON mode/think=false без настройки промпта: dev 0/8 и holdout 0/4 валидных Proposal. После правки промпта и JSON Schema повтор дал 5/8 dev и 3/4 holdout; 3/3 отрицательных случаев корректно пустые, только 4/9 эталонных поручений выданы в валидных ответах. Опасные ошибки: d02 пропущено KK-поручение, d03/h04 выдуман исполнитель, d04/h03 сохранён старый или недоказанный срок, d05 потерян конфликт, h02 потерян второй кандидат срока. Детали по случаям в `eval/results_first_measure.md` и `eval/results_repeat.md`. Отдельный ранний hosted synthetic тест на `gpt-4.1-mini-2025-04-14` до выбора Luna не прошёл: модель дважды пометила цитату только `field=task` при заполненном `deadline_text`; строгая проверка отвергла ответ. Реальные записи в hosted API не отправлялись.
- После выбора Luna короткий прямой синтетический запрос к `gpt-6-luna` успешно вернул ответ (27 токенов). Позднее подключение к `api.openai.com` стало прерывистым: hosted eval остановлен после APIConnectionError/ConnectTimeout; 0 успешных ответов нового прогона, поэтому качества Luna пока не измерено. Сетевые сбои записаны отдельно от модельных ошибок и не обходятся отправкой реальных данных.
- Backend mock: целевые тесты `27 passed, 7 failed` без системного шрифта в тестовом окружении; полный suite дополнительно блокируется отсутствующим `scripts.demo_e2e` на свежем main. Отдельный авторизованный mock E2E с Unicode-шрифтом прошёл: вход, approval, 4 поручения, DOCX и PDF. Ошибки тестового окружения возникли до подключения real pipeline.
- Реальный локальный E2E: технический smoke на 20-секундном фрагменте исходного аудио с `AUTH_MODE=local`, `STT_MODE=real`, `AGENT_MODE=real`, endpoint строго `127.0.0.1:11434/v1`, `qwen3:4b` прошёл через upload → STT/Community-1 → Proposal → approval → DOCX/PDF (`200` оба). STT+диаризация 20.89 с, до Proposal 29.13 с, полный путь 29.52 с; 3 сегмента, 2 акустических голоса, 0 поручений. Это техническая проверка, не оценка качества извлечения. Дата `2000-01-01` была явной тестовой заглушкой обязательного v0.1 API-поля и не использовалась runner при извлечении; требуется nullable meeting_date для настоящей записи с неизвестной датой.
- Окружение smoke: `.venv` использует Python 3.11.11 с установленными на этом Mac Torch/pyannote; `pyproject.toml` требует Python ≥3.12, поэтому перед передачей на другой хост нужно отдельно создать Python 3.12 env и проверить совместимые ML wheels. Бинарные модели присутствуют только в этом checkout и не войдут в Git-коммиты.
- Текущий приоритет пользователя: локальную LLM пока не развивать. Ollama-сервер, запущенный для замеров, остановлен; ранее полученные результаты сохранены как baseline. Основная LLM — OpenAI `gpt-6-luna`, `MODEL_MAIN`/`MODEL_FAST` заданы в ignored `.env` рабочего checkout без ключей. Повторная короткая проверка связи после eval снова дала `ConnectTimeout` до ответа модели; дальнейшие hosted вызовы остановлены до восстановления сети.
