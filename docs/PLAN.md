В проверенном main 7bae7c2 есть самостоятельный frontend (загрузка/запись, редактирование, локальные поручения, DOCX/печать PDF), backend `/api/health`; отдельно есть локальный STT-тест. API/AI-интеграция и approval ещё должны пройти проверки ниже. 16 обнаружимых поручений — результат ручного чтения, не метрика готового извлекателя. Казахская и смешанная речь ещё не проверены.

Уточнение команды: начинаем разработку LLM через OpenAI API на вымышленных данных и переключаем на local без изменения контракта. $50 на API-ключ и $50 на Brev; число ключей неизвестно. Hosted smoke — к 14:15, local smoke — не позже 15:00, real end-to-end — к 15:30. Аудио/тексты предоставленных встреч не участвуют в hosted этапе. Подробнее — STACK.md.

## MVP и границы

- MP3/WAV, до 10 минут, один запуск одновременно; браузерное воспроизведение исходного файла и переход к сегменту.
- Своя STT, автоматическое разделение говорящих, ручное подтверждение связи «голос → имя». Ответственный может быть отделом или человеком, который не говорил.
- Поручение: действие, ответственный либо «не указан», срок дословно, вычисленная дата только при достаточных основаниях, источники, причины проверки. Неуверенность показываем словами, не псевдоточностью 97%.
- Саммари, решения и поручения; просмотр и редактирование; серверное утверждение; DOCX/PDF со шрифтом для казахских букв.
- SSE показывает фактические этапы; mock/replay/live заметно различаются. Не изображать заранее заданный JSON как результат STT.
- Обязательный тест RU на двух исходных записях; отдельные KK и mixed фрагменты собственной записи. Исправленные человеком и автоматические результаты считать отдельно.
- Документация, установка, версии моделей и повторяемый тест столь же приоритетны, как ядро. Рубрики и доказательства — `CRITERIA.md`.

## Не делаем до заморозки

Боты Teams/Zoom/Meet, live streaming, видеозагрузка, СЭД, почта/мессенджеры, голосовая биометрия, аккаунты и роли, облачный деплой, Kubernetes, обучение моделей, vector DB/RAG, multi-agent handoffs ради демонстрации, KenLM, word-level alignment, автоматическая публикация. API вне ядра остаются явно отложенными. В ТЗ входы видеовстреч упомянуты, поэтому не обещаем полное покрытие всех входов.
