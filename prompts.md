## Meiirlan — API и интеграция

```text
Отвечай по-русски. Продолжай текущую backend-задачу Siqyr AI. Сначала проверь свою ветку, незакоммиченные изменения, актуальный main, AGENTS и существующие API/схемы. Сохрани уже сделанное. Frontend Нурдаулета уже реализован на React/Mantine/IndexedDB; не переписывай его.

Ты единственный редактор backend/app/, backend/shared/, backend/requirements.txt, корневых настроек/locks, scripts/, tests/, docs/CONTRACT.md и общего журнала решений. frontend/ принадлежит Нурдаулету; backend/stt/ и backend/agents/ — Alibi. Продолжай существующую ветку своего checkout, не переименовывай чужие ветки.

Сначала передай обоим минимальный согласованный контракт: запрос создания run, ответ/ошибка, сегменты с временем, поручения с evidence, состояния и approval. Используй текущие схемы, расширяй только необходимое; локальный проект v0.2 не считать уже реализованным. Дай один полностью вымышленный fixture и рабочий mock API, чтобы frontend не ждал AI. Согласуй с Alibi интерфейс LLM-адаптера в backend/app/llm.py: ты владеешь транспортом/config, он — промптами и AI-логикой.

Затем реализуй upload → background STT → propose → review/save → approve. Нужны SSE с восстановлением, воспроизведение исходного аудио, хранение raw отдельно от правок, revision и approved snapshot. С Нурдаулетом зафиксируй один путь экспорта: для MVP рекомендуем сохранить его готовый DOCX/печать PDF, передавая утверждённый snapshot; серверные файлы — только если это уже сделано/согласовано. Не делать два экспортера параллельно.

Local по умолчанию, без облачного fallback. Hosted OpenAI только на доверенной синтетике; реальные записи и транскрипты туда не отправлять. Проверь фактический frontend origin — main использует порт 5174. Совместимость старых полей не ломать без REQUEST_CHANGE и ACK потребителя.

Работай блоками до 30–45 минут. Обновляй только свой docs/handoffs/meiirlan.md; STATUS/DECISIONS сводишь ты. Сообщение: READY|BLOCKED|REQUEST_CHANGE; ветка@SHA; версия контракта; что проверено; что требуется от другого. Не утверждай, что коллега получил сообщение, если оно только записано в файл.

Ты интегрируешь main малыми PR/коммитами после проверки автора и потребителя. Только явные пути для git add; без чужих изменений, секретов, весов и записей. Приёмка: новый аудиофайл → реальные результаты → правка → утверждение → экспорт тех же данных. В конце дай коммит, команды запуска/проверки и точный список незакрытых этапов.
```

Не создавай приложение заново, не откатывай UI и не заменяй существующие Mantine/Dexie/React Router, npm и package-lock новым стеком ради старого плана.

Ты владеешь всем frontend/, включая компоненты, стили, domain types, API adapters, зависимости и lock. Ты вправе адаптировать внутреннюю архитектуру по своему более полному контексту и обновлять frontend/AGENTS.md. Backend/shared schemas, backend-код и общий CONTRACT редактирует Meiirlan. Внешний формат обмена меняется только после его ACK; внутренние UI-решения дополнительного разрешения не требуют.

Твоя следующая цель — подключить текущие экраны к API, сохранив интерфейс. Получи у Meiirlan контракт+один synthetic fixture, добавь один API adapter и сначала работай с его mock. Добавь запуск обработки файла, реальные состояния/SSE, отображение source evidence и переход плеера к времени, правку ответственного/срока, speaker mapping и approval с revision. Неизвестные сроки/имена остаются неизвестными. Отдельно показывай example/mock/live/replay: 16 встроенных поручений не являются AI-результатом.

Сохрани готовый DOCX и печать PDF: предпочтительный MVP — экспорт утверждённого snapshot API. Согласуй это с Meiirlan до параллельной работы над экспортом. IndexedDB можно оставить для локальных черновиков; для API-run истина — сервер, без двух несогласованных копий. Не обходи отсутствие API поддельным успешным AI-результатом.

Не переименовывай текущую ветку ради плана. Работай только в своём checkout. Статус/предложения — docs/handoffs/nurdaulet.md, не общий STATUS/CONTRACT. Проверки: npm run build, сохранение существующих функций, API upload→review→approve, reload/reconnect/error, правильные данные в DOCX/PDF. После готовности сообщи Meiirlan commit SHA и результаты для интеграции. Это продолжение разработки, не переработка уже готового интерфейса.

## Alibi — speech и AI

```text
Отвечай по-русски. Продолжай текущую AI/STT-задачу Siqyr AI. Проверь свою ветку, незакоммиченные файлы и рабочее окружение модели; сохрани работающий baseline. Не считай старый план новее своей подтверждённой реализации.

Владение: backend/stt/, backend/agents/, backend/requirements-stt.txt, evaluation/, eval/ и синтетические fixtures в data/synthetic/. Frontend принадлежит Нурдаулету. backend/app/llm.py, API/config и backend/shared/schemas.py — Meiirlan: ты запрашиваешь изменения, не редактируешь их параллельно.

Первым сообщением Meiirlan подтверди фактические интерфейсы transcribe(Path, lang) → list[Segment], async propose(RunInput, emit) → Proposal, async execute(Proposal, emit) → Result. Если они отличаются от твоего рабочего кода, предложи минимальный adapter и согласуй. Передай короткий synthetic fixture, отдельно реальный локальный результат и команды smoke; не включай приватные данные в публичный handoff. Общий CONTRACT обновляет Meiirlan.

Подключи STT и диаризацию: 16 kHz mono, исходная шкала времени, unknown/overlap вместо выдуманного говорящего. Извлечение: действие, ответственный, дословный срок, дата/null, evidence и причины проверки. Исполнитель может не выступать. Конфликтующие сроки требуют проверки, неизвестное не выдумывать. execute после approval ничего не генерирует заново и не рассылает; needs_approval/final эмитит backend.

Сначала разрешён OpenAI на полностью вымышленных тестах, затем local через тот же adapter. API-бюджет $50 на ключ; Brev уже настроен, $50 на GPU/тесты/синтез. Исходные встречи и производные не отправлять в OpenAI/Brev без разрешённого правилами контура; никаких cloud fallback/traces с данными. Неуверенность в OpenAI API/имени модели проверяй через docs_researcher.

Проверь спорные аудиофрагменты, отдельные RU/KK/mixed случаи и ≥2 голоса. Не подмешивай ожидаемые поручения в extractor. 16/16 baseline — ручная обнаружимость; публикуй реальные raw/reviewed метрики и времена отдельно.

Работай блоками до 30–45 минут, продолжай свою ветку. Только свой docs/handoffs/alibi.md: READY|BLOCKED|REQUEST_CHANGE, ветка@SHA, contract version, точная сигнатура/пример, тест и запрос. В main интегрирует Meiirlan. Новые общие зависимости — через запрос ему; не переписывать root lock. Сообщи по отдельности готовность STT, diarization, extraction и E2E, а не одним «AI готов».
```
