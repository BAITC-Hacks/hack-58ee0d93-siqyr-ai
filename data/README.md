# data/

Все данные здесь **синтетические**: имена вымышленные, записи смоделированы командой.
Реальные записи совещаний и персональные данные в репозиторий не попадают.

| Папка | Что | Владелец |
|---|---|---|
| `seed/` | демо-совещания (`*_meeting.json`: транскрипт + эталон поручений), seed для БД | Meiirlan |
| `samples/` | аудио для демо, записали сами по сценарию; 16 кГц моно WAV | Alibi |
| `synthetic/` | сгенерированные eval-кейсы (`*.jsonl`) с пометкой модели и промпта | Alibi |
| `runtime/` | SQLite, загрузки, экспорт — создаётся при запуске, в git не попадает | — |
